# 路线图与验收门槛

以可验证链路为准，不以文件存在或测试替身通过代替真实服务验收。以下不是发布时间承诺。

## 已完成的本地基础

- 浏览器单窗口脚本演示，与 Rust 服务分开运行。
- Rust/Axum 开发令牌身份、SQLite 私聊与任务、权限负面测试。
- 私有委派提案、显式共享确认、人工接单/交付/验收、修订和提案幂等控制。
- 聊天界面自动轮询与失败退避；个人 Agent 配置存储 API。
- DSH SDK 适配及严格结构化提案协议，具备离线测试；尚未真实模型验收。
- Worker 队列、消费/发布合同和 GitLab 传输库；均未形成可执行的端到端链路。
- 私有启动工具与 SSH 试运行说明；尚未远端部署。

## 接收方 Agent 文本起草设计

[接收方起草合同](recipient-drafting.md) 定义 #14 及后续 #11/#15/#16 的接口、私密草稿、只追加交付、修订与回执恢复边界。对应的私密起草接口、协议、聊天内审阅交付与共享时间线已在本地实现并完成离线验收；不代表已发布、真实模型已验收或代码执行已启用。详见 [本地路线图验收](roadmap-local-verification.md)。

## 下一阶段，按依赖顺序

1. **完成单窗口真实模型闭环**：授权配置提供商和密钥，验证 DSH 的模型调用、工具禁用、上下文边界、提案和错误处理。用真实浏览器完成双身份验收。普通聊天超时不得自动重放。
2. **完成个人配置到运行时的绑定**：安全密钥供给、受控模型目录、每用户模型路由、角色调度及配额；在聊天内提供配置交互。当前保存角色并不创建 Agent 军团。
3. **建立可信代码执行链路**：修复证据与不可信测试共处的问题，独立采集精确提交证据；真实沙箱验证网络/文件/资源限制、取消和清理后才考虑启用消费服务。当前内置执行器保持禁用，禁止用宿主 shell 替代。
4. **完成受控交付**：授权的分支上传、候选摘要与精确 SHA 绑定的发布确认、GitLab 草稿 MR 与真实 CI 联调、不确定结果恢复；保持人工验收，不自动合并。现有传输库不能独立满足此阶段。
5. **完成可访问的私有试运行**：在已授权主机上启动服务，验证 SSH 访问、双浏览器隔离、重启持久化与备份恢复。仓库脚本不是云端实例，当前没有已验证的后端访问地址。
6. **生产化前置门槛**：真实登录/OIDC、租户策略、速率限制、密钥管理、审计/保留与监控、安全审查；根据并发和部署需求评估 PostgreSQL。继续验证提案确认边界与普通聊天幂等边界；旧的直接任务创建入口已移除。
7. **低风险试点**：完成上述相关门槛后，选 10–20 个低风险任务，记录协调、编码、审查、返工和费用，与人工流程比较。

多层军团、任意外部发送、自动合并、个人电脑常驻节点和跨公司网络不在当前优先范围。未通过真实验证的能力必须保持显式关闭或标注未接通。
