# 界面用语

用户界面以动作和结果命名。协议字段、数据库状态与审计事件保持原名，避免影响兼容性。

| 概念 | 界面用语 | 不再使用 |
| --- | --- | --- |
| 接收人接受任务 | 接手、待接手 | 接单、待接单 |
| 任务或记录的 revision | 版本、任务版本 | 修订 |
| 角色配置的 revision | 角色版本 | 配置版本、角色配置版本 |
| runtime | 服务模式；已知模式用真实模型 / 离线演示 | 运行时 |
| 个人角色管理 | 个人角色设置 | 个人 Agent 配置 |
| coordinator / researcher / writer / reviewer | 管家 / 研究 / 写作 / 审阅 | 在设置控件中直接展示英文标识 |
| 用户确认共享前 | 委派提案、生成提案 | 已委派 |
| 用户确认共享后 | 确认共享并委派 | 自动执行 |
| 模型生成交付文字 | 私密交付草稿 | 已交付 |
| 人工审阅后的任务提交 | 人工交付、确认交付 | 执行结果 |
| completed / canceled 的列表收纳 | 已完成 / 已取消 | 删除任务 |

任务筛选只控制显示，已完成与已取消的历史仍可查看。消息的“重新问”只填入输入框，“生成委派提案”仍需第二次明确确认才共享。

## 验证边界

键盘操作由单元和 Chromium 测试覆盖；本机 Orca 42 + AT-SPI 已实际走通登录、引导、输入、任务接手、多轮草稿、交付与验收，核对了读屏软件生成的朗读日志。人工听觉体验、实体手机输入法与系统通知的后台节流仍需试用设备验证。
