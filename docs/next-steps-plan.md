# 下一步开发计划

制定日期：2026-11-06 · 基线：`master` @ `8e1725d`

本文是工作计划，不是发布承诺。各项完成的标准以"验收"一列为准；离线测试或模拟替身通过，不能当作真实环境的验收。

## 1. 现状

**单机上已经跑通的完整链路**：用真实 DeepSeek 模型聊天 → 自然语言委派生成提案 → 确认，可附带共享材料 → 接收方接单 → 接收方 Agent 起草（只有自己可见）→ 人工审阅后交付 → 验收或退回。全程记录可回放的时间线，界面上有"工作"索引和聊天时间戳。

**离真实使用还差的三件事**：

1. **两个人没法分别在自己的电脑上用**：Hub 只监听本机（loopback）；用户在初始化时就固定了；有新任务也没有提醒。
2. **Agent 能做的事很有限**：只能读到委派人手动粘贴的材料，只能产出文字，不能使用工具，也不能执行代码。
3. **缺少长期运行的保障**：没有备份恢复，没有运行日志；界面这周改了多轮，但没有真实浏览器测试来防止改坏。

**方向**：先让两个真人试用一周，用实际使用数据决定后面做什么，不要继续在单机上堆功能。

### 阶段 B：让 Agent 真正有用（约 1～2 周，具体做哪几项看试用反馈）

| # | 任务 | 为什么要做 |
|---|---|---|
| B1 | 共享材料支持上传文件（先支持文本、Markdown，之后再支持 PDF 转文字），提高 12KB 的上限 | 现在只能手动粘贴，这是起草质量的瓶颈 |
| B2 | 起草可以多轮修改：补一句要求就生成新版本，保留历史版本（和 U9 一起做） | 现在只能整篇重新生成，或者自己手改 |
| B3 | 长对话的上下文管理：超出 40 条或 60KB 后做摘要，不再直接截掉最早的内容 | 聊得越久，管家越"失忆" |
| B4 | 让角色真正有区别：研究、写作、审阅各用不同的提示词，起草时自动推荐合适的角色 | 现在几个角色差别不大 |

### 阶段 C：有条件再做（必须先通过对应的验收门槛）

- **让 Agent 只读访问代码仓库**：前提是沙箱真实验证过（`docs/archive/roadmap.md` 第 3 步）。
- **正式部署**：OIDC 登录、TLS、多租户，取代 SSH 隧道方案。
- **PostgreSQL 和连接池**：等真的出现并发瓶颈再做。

## 3. 界面与交互

### P0：天天会碰到、现在体验明显不好的地方（和阶段 A 同时做，试用前必须完成）

| # | 问题 | 改法 |
|---|---|---|
| U1 | "提交交付"和"取消原因"用的是浏览器原生的 `prompt()` 弹窗：只能输入一行，长文本没法看也没法改，样式也和页面不一致 | 改成在卡片里展开的编辑框：多行输入，预填草稿内容，提交前预览一次 |
| U2 | 管家的回复不渲染 Markdown，表格、列表直接显示成原始符号 | 安全地渲染一部分 Markdown（不允许 HTML），代码块加复制按钮 |
| U3 | 刷新后要手动点"核对发送状态" | 页面加载后自动查询回执状态（只读，不会重发），查到结果就直接显示回复；恢复面板只在确实查不到时出现 |
| U4 | 提案只能"确认"或"拒绝"，接收人或摘要不对就只能拒绝后重说 | 加一个"修改后确认"：可以直接编辑摘要和接收人；摘要仍然只能来自原话，或者由委派人手动改写 |
| U5 | 旧的待确认提案越积越多 | 超过一天没处理的提案自动折叠成"N 个未处理的提案"，支持一键全部拒绝 |

### P1：提升效率（试用后根据反馈挑选）

| # | 问题 | 改法 |
|---|---|---|
| U6 | 有新任务时没有任何提醒 | 标签页标题显示待办数"(1) Agenct"，可选系统通知（侧栏角标已经有了） |
| U7 | 任务一多就很难找 | 加筛选：待我处理、我发起的、已完成；已完成的自动归档 |
| U8 | 消息上没有任何操作 | 鼠标悬停时显示：复制、"把这段交给某人"（直接生成提案）、重新问 |
| U9 | 想让 Agent 改草稿只能整篇重新生成 | 草稿面板里加一个输入框写修改要求（如"更简短""换成英文"），保留历史版本 |
| U10 | 个人角色配置（`/agents`）还是一堆原生表单控件 | 做成设置面板：卡片式的角色列表、开关、说明 |

### P2：打磨和一致性（穿插着做）

- **U11 统一用词**：整理一份用语表，替换"修订、运行时、接单、配置版本"这类开发术语，全站统一。
- **U12 新手引导**：空状态的示例句可以直接点击填进输入框；第一次登录时有 3 步引导。
- **U13 图标**：工作索引里的状态图标从 ◔ ✓ ○ 这类字符换成统一的 SVG。
- **U14 键盘与无障碍**：Esc 关闭面板，快捷键切换任务抽屉，焦点顺序合理；用读屏软件实际走一遍。
- **U15 手机端专项**：底部导航和输入框的安全区、键盘弹起后的布局、大按钮好点。

### 防止界面再被改乱

- 真实浏览器交互测试（A5），覆盖发送、刷新恢复、委派、起草、交付。
- 固定尺寸的截图对比：桌面 1330 和 1440、手机 400，再加深色模式，每个 PR 自动截图，和基准图有明显差异时 CI 提醒。
