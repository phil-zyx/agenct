# Security

This project is a browser-local simulation, not a production agent platform. Role selection is not authentication. All rooms are readable by the current browser. Do not enter secrets, private conversations or proprietary code.

No security audit has been performed. Do not deploy this prototype as a trusted authorization layer. A real implementation requires server-side identities and policy enforcement, credential isolation, sandboxing, controlled publishing, independent verification and recovery.

Before public release, the maintainer must configure a private vulnerability reporting channel. Until one exists, do not publish exploit details or sensitive data in public issues; ask the maintainer for a private reporting route.
