# Contributing

Start with an issue describing the problem and expected behavior. Keep changes small and maintain the chat-first experience. Do not imply that scripted behavior is a real model, account system or privacy boundary.

Run `npm test` and `npm run check`. UI changes should also be tested manually for repeated actions, close/reopen, refresh persistence, failure and cancellation. Add regression tests for changed state transitions.

Do not commit credentials, personal data, deployment metadata or local browser exports. Do not submit sensitive vulnerability details in a public issue. Contributions are provided under the MIT License.
