# Agenct 品牌素材

| 文件 | 用途 |
| --- | --- |
| `agenct-icon.svg` | 应用图标：墨绿圆角底、浅色标志。浏览器标签页、侧栏、“管家”头像。 |
| `agenct-icon-32.png`、`agenct-icon-180.png` | 不支持 SVG 图标的浏览器，以及手机“添加到主屏幕”。由 `agenct-icon.svg` 渲染。 |
| `agenct-mark.svg` | 透明底标志（墨绿），只用于浅色背景。 |
| `agenct-wordmark.svg` | 字标 “Agenct”，c 的顶笔延伸成 t 的横笔。登录页内联同一组路径，颜色随主题变化。 |

- 主色：墨绿 `#1F5440`；浅色标志 `#F3F4EC`。界面强调色 `--brand` 与之一致。
- 标志：一笔写成的 A，横梁压过右腿后绕成闭合的圈，表示任务交出去、再回来。方向来自 Gemini 概念图，按 64×64 网格重新绘制；8 单位线宽，16 像素下仍可辨认。
- 字标：Outfit Bold（700）字形转成的轮廓，加入 “ct” 连写。

Outfit 由 The Outfit Project Authors 设计，以 SIL Open Font License 1.1 授权（https://openfontlicense.org）。字标只包含由该字体转出的轮廓，未分发字体文件。
